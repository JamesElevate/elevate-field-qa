Field QA

Check Topcon field data against the calc before it leaves site.

tool v17 · rules 8 Nov 2026

1Job type

Pick the job type first. It sets the tolerances and whether heights are graded.

2Files

Use the upload file that went to the controller as the calc, and the MXL exported from Topcon Field after the job. Export with raw observations so setups, backsights and resections can be checked.

Calc file The upload / pre MXL from Topcon Office
Field file The MXL downloaded from Topcon Field
Choose a job type and add both files.

3Results

The verdict for each report section, the plans and the findings list appear here after you check a job.

4Download

Each download asks you to confirm the save. The zip holds everything, including the DXF drawings for CAD. Open a DXF in BricsCAD and Save As DWG to amend it; it is drawn in real MGA coordinates at the plotted scale, with named layers.

This is a checking aid. A green report means the field data agrees with the calc and with itself inside the tolerances below. It does not replace review and sign-off by a registered surveyor, and a senior can override any result with a reason on file.
