# Elevate Field QA

Field QA check tool for Topcon MXL files (Elevate Surveying), served by GitHub Pages at qa.elevatesurveying.com.au. Files are processed in the browser and never uploaded.

Edit the sources in `src/` (page.html template, engine.js, render.js, logo.txt), then run `python3 build.py` to regenerate `index.html` and commit both.
